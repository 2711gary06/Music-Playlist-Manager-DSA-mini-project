# Music-Playlist-Manager-DSA-mini-project
A Music Playlist Manager developed using C++, implementing Data Structures and Algorithms to manage songs, create playlists, and navigate between tracks with operations like play, next, previous, add, delete, and search.

Music Playlist Manager | C++

A console-based Music Playlist Manager built using C++ and Data Structures & Algorithms (DSA). This project allows users to manage their music collection, organize playlists, and navigate through songs using fundamental data structure operations.

📌 About the Project

The Music Playlist Manager is a mini DSA project developed in C++ to demonstrate the practical application of data structures in a real-world scenario.

It provides basic music playlist management functionalities such as adding songs, removing songs, searching for tracks, and navigating between previous and next songs.

The project focuses on implementing data structures to make playlist operations organized and efficient.

✨ Features

➕ Add new songs to the playlist.

❌ Remove songs from the playlist.

🔍 Search for songs by title.

▶️ Play the selected song.

⏭️ Navigate to the next song.

⏮️ Navigate to the previous song.

📃 Display all songs in the playlist.

🔄 Manage playlist navigation.

🧠 Data Structures & Algorithms Used

Doubly Linked List: Supports forward and backward navigation between songs.

Searching: Finds songs based on their titles.

Insertion: Adds new songs to the playlist.

Deletion: Removes songs from the playlist.

Traversal: Displays and navigates through the playlist.

⚙️ How to Run the Project

Clone the repository:

git clone https://github.com/your-username/Music-Playlist-Manager.git

Open the project folder:

cd Music-Playlist-Manager

Compile the C++ source file:

g++ main.cpp -o playlist

Run the application:

./playlist

For Windows:

playlist.exe
